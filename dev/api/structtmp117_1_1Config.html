Detailed Description

Everything EnsureInitialized() and Configure() write to the chip.

The defaults are the factory reset values (section 7.3.1 and Table 7-3), so Config{} changes nothing on a chip that was just reset except the driver-side timeouts and opt-ins. Fields with a unit carry it as a suffix. Every field has a default (KB-CPP20-031).
