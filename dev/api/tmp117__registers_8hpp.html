Detailed Description

TMP117 register map: pointers, bit fields and reset values (datasheet section 7.6).

Every register is 16 bits wide, sent most significant byte first (SNOSD82D section 7.5.3.1, p. 20). The pointer register is one byte and its upper four bits must be 0 (Figure 7-9, p. 22). Section and page numbers are those of SNOSD82D, the TMP117 datasheet, Rev. D.
