# TMP117 Driver API reference {#mainpage}

The classes, types and registers of the TMP117 driver, generated from the headers in `inc/`.

Start with tmp117::TMP117, the driver, and tmp117::I2cInterface, the base of the port you write. Errors are
tmp117::Error inside tmp117::Result; the configuration is tmp117::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">TMP117 Driver
documentation</a>.
