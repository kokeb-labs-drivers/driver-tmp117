Detailed Description

Public types of the TMP117 driver: errors, Result<T>, configuration and presets.

Everything here is plain data with no platform dependency, so handlers, tests and tools can include it without the driver template. The configuration defaults are the chip's factory reset values (SNOSD82D Table 7-3, p. 25), so Config{} describes a chip that was just reset.
