Detailed Description

The I2C port of the TMP117 driver: the CRTP base, the I2cPort concept and the register framing.

The driver never calls an SDK. It calls hooks on a class you derive from tmp117::I2cInterface<Self>:

Hook Contract
bool EnsureInitialized() noexcept Bring the bus up on the first call; true at once afterwards
bool Write(uint8_t addr, const uint8_t* data, std::size_t len) noexcept START, addr + W, len bytes, STOP; false on a NACK or bus error
bool WriteRead(uint8_t addr, const uint8_t* tx, std::size_t tx_len, uint8_t* rx, std::size_t rx_len) noexcept START, addr + W, tx, repeated START, addr + R, rx_len bytes, STOP

addr is the 7-bit address. The port moves raw bytes: the pointer travels in the payload, and the port never retries or configures the chip. Optional hooks: void Log(LogLevel, const char*) and bool ReadAlertPin(bool& level) (the raw level of the ALERT pin; false when the pin cannot be read), and void DelayUs(uint32_t), which every wait needs. What the chip needs from the bus is below as constexpr values (kI2cAddress, kMaxClockHz, kRepeatedStart); a port checks its settings against them with static_assert.
