Package and pins¶

The TMP117 comes in a 6-pin WSON (DRV, 2 mm square) and a 6-pin DSBGA (YBG, 1.53 x 1.00 mm). The pins are the same signals in both:

The TMP117 seen from the top, in its WSON-6 package. Pin 1 is marked by the dot; the numbers run counter-clockwise from it. Each pad is coloured by the pin's electrical type (legend below). Next to it is the pin's name and, in mono, the hook of the driver's port that drives or reads it; a pin without a hook is not used by the driver. The dashed square is the exposed pad.

Source of this table and of the chip figures: docs/hardware.yml.

The DSBGA balls are A1 SDA, A2 SCL, B1 V+, B2 GND, C1 ADD0 and C2 ALERT. The thermal pad of the WSON is left unconnected; the datasheet's layout page (section 10) is the place to check that for your board.

ALERT and the driver's own reads. In alert mode a read of Configuration clears HIGH_Alert and LOW_Alert and so releases the ALERT pin (7.4.4.1, p. 16). The driver reads Configuration in ReadStatus(), WaitDataReady(), StartOneShot(), CheckHealth() and the settle after a failed write, so an application that services ALERT as a level interrupt can find the pin released by that polling. The flags are kept in GetLatchedStatus(); see the API guide. Not hardware-verified.

Inside the sensor¶

Figure description and sources

The TMP117's function blocks inside its outline. Arrows between blocks carry signals or data in the direction they point (both ways where they have two heads). The package pins stand on the left and right edges with their numbers, each wired to the block it reaches.

Drawn from: docs/hardware.yml; inc/tmp117.hpp; inc/tmp117_i2c_interface.hpp.

The temperature sensor is an internal bipolar transistor and an ADC. The control logic and its oscillator run the conversion cycle, the register bank holds the settings and the result, and the EEPROM supplies the register values at power-up. The serial interface is I2C and SMBus compatible.

Export a circuit for a schematic or PCB tool: kokeb-docs hardware --kicad-netlist OUT.net --circuit typical.

Both pull-ups are 5 kΩ in the datasheet's figure and can be higher or lower. SCL needs a pull-up only if the MCU pin is open drain. Use a ceramic bypass capacitor rated for the whole temperature range and place it close to V+. Do not heat the chip with its own supply current: the datasheet's section 8.2.2.2 gives the self-heating, which matters when averaging is high and the cycle is short.

Clock 5 kHz to 400 kHz (fast mode). The datasheet lists 1 kHz, but a 3-byte write then outlasts the 20 ms minimum bus timeout (A15)
Address 7-bit, 0x48 to 0x4B from ADD0: GND 0x48, V+ 0x49, SDA 0x4A, SCL 0x4B; pass it to the constructor

One I2C register word of the TMP117, 24 bits in a row from the most significant (left, sent first) to the least significant (right). Each row is one kind of frame; each coloured box a field, with its first and last bit number under it.

Drawn from: docs/hardware.yml; inc/tmp117.hpp; inc/tmp117_i2c_interface.hpp.

Figure description and sources

Two participants, the host and the TMP117. The host sends START, address 0x48 with the write bit and the pointer byte 0x00, Temp_Result. It repeats START with address 0x48 and the read bit. The chip returns the high byte and the low byte of the register. The host answers the last byte with NACK and ends the transaction with STOP.

Drawn from: docs/model/bus-frame.seq.yml.

The waveform under these frames is on On the bus. The driver also uses two special transfers: the general-call reset (address 0x00, byte 06h, only with allow_general_call) and, in a later release, the SMBus alert response.

Deinitialize() puts a chip it has reached in shutdown; on a driver that never reached the chip it sends nothing (row N1 of the decision table). The supply is 1.8 V to 5.5 V over the whole temperature range, and 1.7 V up to 70 °C (6.3, p. 5).

Silicon revisions¶

The Device_ID register holds the revision in bits 15:12 and the part in bits 11:0 (0x117). The datasheet defines no value for any revision, so the driver accepts any, reports it with GetRevision() and does nothing different for it. A TMP119 has 0x2117, which this driver reads as revision 2 of a TMP117: it cannot tell the two apart (A13). The grades TMP117A, M and N share the register map and differ in accuracy and range; the chip does not say which one it is.
